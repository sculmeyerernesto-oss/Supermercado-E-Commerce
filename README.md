## Descripción del proyecto

Desarrollo de una plataforma web de comercio electrónico para un
supermercado, tomando como referencia comercial a IC Norte.

La plataforma permitirá consultar productos, gestionar un carrito
de compras y realizar pedidos con pagos simulados. Incluirá un panel
administrativo para gestionar productos, inventario, ventas y entregas.

El proyecto se plantea para un supermercado en general y no representa
un sistema oficial de IC Norte.

## Problema que se busca resolver

La falta de un canal de ventas en línea limita las posibilidades de
consultar productos y comprar a distancia. Además, gestionar pedidos
e inventario por separado puede generar errores de disponibilidad
y dificultades para dar seguimiento a las ventas.

## Objetivo general

Desarrollar una plataforma web que facilite las compras en línea y
centralice la administración de productos, inventario y pedidos de
un supermercado.

## Funcionalidades previstas

### Cliente

- Registro e inicio de sesión.
- Consulta del catálogo de productos.
- Búsqueda y filtros por categorías y precios.
- Consulta de precios y disponibilidad.
- Gestión del carrito de compras.
- Registro de pedidos.
- Pagos simulados.
- Selección de entrega a domicilio o retiro en tienda.
- Consulta del estado y del historial de pedidos.

### Administrador

- Gestión de productos y categorías.
- Actualización de precios y existencias.
- Consulta y gestión de pedidos.
- Seguimiento de los estados de pago.
- Actualización de los estados de entrega.
- Consulta de ventas.

## Inventario y pedidos

Se prevé verificar y reservar las existencias al registrar un pedido.
Si el pedido se cancela o la reserva vence, las unidades se liberarán.

El sistema deberá evitar que una solicitud repetida genere pedidos
duplicados o descuente el inventario más de una vez.
